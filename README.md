Data Cleaning & Visualization

Project Overview

This project focuses on cleaning and visualizing the California Housing dataset using Python.

The main goal is to preprocess the data, handle missing values and duplicate records, and create meaningful visualizations to understand the dataset.

Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

Data Cleaning

The following data preprocessing steps were performed:

- Checked for missing values
- Handled missing values
- Removed duplicate records
- Performed basic data preprocessing

Data Visualization

The following visualizations were created:

- Median House Value Distribution
- Housing Median Age Count
- Correlation Heatmap

Dataset

The project uses the California Housing dataset.

The dataset file is included in this repository as "housing.csv".

Project Files

- "California_Housing_Data_Analysis.ipynb" — Python code, analysis, and visualizations
- "housing.csv" — Dataset
- "README.md" — Project documentation

Conclusion

This project provided hands-on experience in data cleaning, preprocessing, exploratory data analysis, and data visualization using Python libraries.
